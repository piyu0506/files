STQA PRACTICALS — SETUP AND RUN COMMANDS
========================================
For the existing practicals only: Practical 2, 3, 5, 6, and 8.
Run these commands in Windows PowerShell / VS Code terminal.
Start from the OUTER Lab folder. Do not use Lab\Lab.

Prerequisites
-------------
- Python installed (use `py --list` to see available versions).
- Java JDK and Maven for Practical 6.
- Google Chrome and internet access for Practicals 5 and 6.
- Internet access to install Python packages and Maven dependencies.
- Practical 3 mutation testing may be easiest in WSL if native Windows
  execution fails because of Mutmut process/fork compatibility.

IMPORTANT FINAL-CHECK FINDING
-----------------------------
Prac3/setup.cfg currently contains:
    [mutmut]
    source_paths = inventory.py

Change it to:
    [mutmut]
    paths_to_mutate = inventory.py

Save the file before running mutation testing. The current key `source_paths`
may not be recognized by the Mutmut version being used.

PRACTICAL 2 — PYTEST
--------------------
From the Lab root:

    cd Prac2
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install pytest
    .\.venv\Scripts\python.exe -m pytest -v

Expected check: the division test should assert divide(36, 6) == 6.

PRACTICAL 3 — INVENTORY + MUTATION TESTING
------------------------------------------
From the Lab root:

    cd Prac3
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install pytest "mutmut<3"
    .\.venv\Scripts\python.exe -m pytest -v

After normal tests pass, run mutation testing:

    .\.venv\Scripts\python.exe -m mutmut run
    .\.venv\Scripts\python.exe -m mutmut results

If Mutmut reports a configuration or Windows process/fork error, do not keep
reinstalling versions randomly. Use the Mutmut version and environment that
match the practical instructions; WSL may be required for Mutmut 3.x.

PRACTICAL 5 — SELENIUM
----------------------
The folder is named Prac5 in this project. From the Lab root:

    cd Prac5
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe -m pip install pytest

Run with pytest:

    .\.venv\Scripts\python.exe -m pytest -v -s test_internet_heroku.py

Or run the script directly:

    .\.venv\Scripts\python.exe test_internet_heroku.py

Requires Google Chrome and internet access to SauceDemo. Selenium Manager may
need internet access to obtain a compatible ChromeDriver. The script performs
a checkout flow on the SauceDemo test website.

PRACTICAL 6 — JUNIT + SELENIUM + MAVEN
--------------------------------------
From the Lab root:

    cd Prac6
    java -version
    javac -version
    mvn -version
    mvn clean test

If Maven is not on PATH but a Maven distribution is included inside Prac6,
use its actual path, for example:

    .\apache-maven-3.9.6\bin\mvn.cmd clean test

The current project structure is Prac6\src, Prac6\target, and Prac6\pom.xml.
The test uses Chrome in headless mode. If the test fails to start Chrome,
check Chrome installation and Selenium Manager/driver access. A Java compiler
warning about source/target 11 on a newer JDK is not by itself a build failure.

PRACTICAL 8 — SOAP SERVICE AND CLIENT
-------------------------------------
From the Lab root:

    cd Prac8
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Terminal 1 — start the service and leave it running:

    .\.venv\Scripts\python.exe calculator_service.py

Terminal 2 — open another PowerShell terminal, return to Lab root, then run:

    cd Prac8
    .\.venv\Scripts\python.exe test_client.py

The client should print addition and division results and catch the SOAP fault
for division by zero. The service must stay running in Terminal 1.

FINAL NOTES
-----------
- Run each practical from its stated folder.
- If `py` is unavailable, use `python` if it points to a supported Python
  installation.
- Do not copy `.venv` folders to another laptop. Recreate environments there
  using the commands above.
- `target` in Prac6 is generated by Maven; `mvn clean test` recreates it.
- Practicals 1, 4, 7, 9, and 10 are not included here because they are not
  implemented in the current project, as requested.
